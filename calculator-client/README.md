# Calculator Client

A simple web-based user interface for the Calculator Service.

## Usage

Open `index.html` in a browser. Make sure the Calculator Service is running on `http://localhost:3001`.

Enter two numbers, select an operation, and click **Calculate** (or press Enter). The result will appear below.

## Development

No build tools required. Just serve the folder with any static file server (e.g., `npx serve .`).
